# A leftover asks its neighbours before it asks the script

A transcript region the spine did not claim is scored first against the script lines its
neighbours map to. Only if no neighbour reads like it is the rest of the script asked —
and if the line it then matches has no take yet, the leftover *becomes* that line's take.

## Context

The spine is established before anything else is classified: the monotonic mapping of
transcript regions to script lines is what gives leftover classification a reference
point at all. Reversing that order means every candidate span competes globally, and on
material with retakes the same sentence appears three times over — repeated phrases steal
each other's matches and nothing says which copy belongs where. Neighbours first is what
keeps them apart.

But a line re-recorded at the end of a session sits nowhere near where it is written, and
a monotonic spine cannot claim a pickup take by construction. Asking only the neighbours
would leave every pickup unplaced, and the line it belongs to reported as missing from a
recording that contains it.

## Consequences

The second pass is what makes "assembled in script order regardless of the order spoken"
true rather than aspirational.

A leftover that finds its line this way yields only the part of it that reads as the
line; the rest goes back on the pile and is labelled in its own right — see decision 0004.
